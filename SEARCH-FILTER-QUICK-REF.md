# Search & Filter - Quick Reference Card

## 🔍 Search
| What | How |
|------|-----|
| **Search records** | Type in search bar at top |
| **Clear search** | Tap X button in search bar |
| **What it searches** | Title, category, description |

---

## ⚙️ Filter Modal
| What | How |
|------|-----|
| **Open filters** | Tap ⚙️ button next to search |
| **Apply filters** | Tap "Apply Filters" button |
| **Clear all** | Tap "Clear All" in modal |

---

## 📅 Date Range Options
- **All Time** - No date filter (default)
- **Today** - Records from today only
- **This Week** - Last 7 days
- **This Month** - From 1st of current month
- **Custom** - Pick your own date range

---

## ✅ Status Filter (Bills Only)
- **Unpaid** - Bills due but not paid
- **Overdue** - Bills past due and not paid
- **Paid** - Bills marked as paid

💡 **Tip**: Uncheck status types you DON'T want to see

---

## 🔢 Sort Options

### Expenses Tab
- **Default** - Newest first
- **Newest First** - Most recent first
- **Oldest First** - Oldest first
- **Highest Amount** - Largest first
- **Lowest Amount** - Smallest first

### Bills Tab
- **Default** - Unpaid first (nearest due), then paid
- **Newest First** - Most recent due date
- **Oldest First** - Oldest due date
- **Highest Amount** - Largest bill first
- **Lowest Amount** - Smallest bill first

---

## 🎯 Common Use Cases

### Find Specific Bill
```
Type bill name in search → Done!
Example: Type "Meralco" to find Meralco bills
```

### Check Overdue Bills
```
Tap Filter → Uncheck Paid & Unpaid → Keep Overdue only → Apply
```

### This Month's Expenses
```
Tap Filter → Select "This Month" → Apply
```

### Large Expenses
```
Tap Filter → Select "Highest Amount" → Apply
```

### Upcoming Bills Only
```
Tap Filter → Uncheck Paid & Overdue → Keep Unpaid only → Apply
```

---

## 💡 Quick Tips

✅ **Combine filters** - Use search + status + date together  
✅ **Smart search** - Type partial words ("mera" finds "Meralco")  
✅ **Case doesn't matter** - "FOOD" = "food" = "Food"  
✅ **Blue button** - Filter button turns blue when active  
✅ **Result counter** - Shows "X of Y" when filtering

---

## 🚨 Troubleshooting

| Problem | Solution |
|---------|----------|
| Can't find record | Check spelling, try partial search |
| No results shown | Tap "Clear All" to reset filters |
| Filter not working | Make sure you tapped "Apply Filters" |

---

## 📱 Visual Indicators

| Icon/Color | Meaning |
|------------|---------|
| 🔵 Blue filter button | Filters are active |
| ⚙️ Gray filter button | No filters active |
| "Showing X of Y" | X records match, Y total |
| ❌ X button | Clear search text |
